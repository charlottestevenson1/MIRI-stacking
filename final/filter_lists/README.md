# Filter Lists

This folder contains the filter definitions used by the pipeline:

- `filter_list_s.txt`: filters available in GOODS-S.
- `filter_list_n.txt`: filters available in GOODS-N.
- `filter_list_miri.txt`: the MIRI filters.
- `filter_list_wide.txt`: the eight wide NIRCam filters followed by the eight wide MIRI filters.
