# Required FITS Files

Place the following catalogue files in `Final/FITS files/`:

1. `hlsp_jades_jwst_nircam_goods-s_photometry_v5.0_catalog.fits`
   - Rename it to `goods-s catalog.fits`.
2. `hlsp_jades_jwst_nircam_goods-n_photometry_v5.0_catalog.fits`
   - Rename it to `goods-n catalog.fits`.
3. `JADES_DR5_z_gt_8_Catalog_Hainline.fits`
   - Keep this filename unchanged.

The GOODS-S catalogue supplies source coordinates for cutouts. The Hainline catalogue
supplies redshifts for assigning objects to redshift bins.
