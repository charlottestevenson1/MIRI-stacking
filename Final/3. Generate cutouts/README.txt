This code generates and then masks the 5" cutouts which will subsequently be stacked. 
It requires input of the MOSAIC DIRECTORY, which may be an external hard drive location or can simply be rerouted back to Final/FITS files.

Run 'cutout generator.py' first, and then 'cutout masking.py'.

This will create two new folders in this folder titled 'Unmasked cutouts' and 'Masked cutouts' (pretty self explanatory).
